# Asset Pipeline

## A — Listos para V1
Se seleccionaron fotografías reales del Drive del cliente para denim, graphic tees, conjunto técnico y perfumería.

## B — Requieren retoque
- Jeans: portada limpia y uniforme sin alterar lavado, bolsillos, costuras, silueta o color.
- Graphic tees: aislar prendas para cards primarias, conservando fotos de tienda como imágenes secundarias/editoriales.
- Set negro: aislamiento limpio para catálogo.

## C — Assets por crear
- Fondo estudio claro con branding final integrado discretamente.
- Hero/campaign composition cuando exista nombre y logo definitivos.
- Ghost mannequin o crops controlados cuando deban excluirse rostro, manos o zapatos.

## D — Secundarios/editoriales
Las fotografías in-store funcionan mejor como hover, lookbook y media secundaria.
Los perfumes mantienen una dirección más sensorial y atmosférica que el denim.

Regla: ningún proceso de IA puede cambiar características reales del producto.
